# Titanic Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing the Titanic passenger dataset from Kaggle. It demonstrates how data quality issues can be identified and handled using Python.

## Dataset
- **Source:** Kaggle
- **Dataset:** Titanic - Machine Learning from Disaster
- **File:** train.csv
- **Original Dimensions:** 891 rows and 12 columns

Dataset link: https://www.kaggle.com/competitions/titanic/data

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Tasks Performed
1. Dataset inspection and description
2. Missing-value identification and handling
3. Duplicate-record detection and removal
4. Categorical-value and data-type checks
5. Outlier detection using the IQR method
6. Feature and target identification
7. Categorical encoding
8. Numerical standardization
9. Log transformation of ticket fares
10. Feature engineering
11. Train-test splitting and leakage-safe preprocessing
12. Final data quality checks

## Files
The repository contains the completed Jupyter notebook and, where applicable, the processed datasets and fitted preprocessing pipeline.

## Objective
The objective is to demonstrate the importance of data cleaning and preprocessing and prepare the dataset for further analysis.
